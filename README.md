# 💇‍♀️ Hall Jale – Landing Page

## 📌 Sobre o projeto

A **Hall Jale** é uma Landing Page desenvolvida para apresentar um salão de beleza de forma moderna, elegante e totalmente responsiva. O projeto foi pensado para oferecer uma experiência intuitiva aos visitantes, destacando os principais serviços, diferenciais da empresa e facilitando o contato com potenciais clientes.

A interface possui um design sofisticado, combinando elementos visuais harmoniosos, animações suaves e uma organização estratégica do conteúdo para transmitir profissionalismo e credibilidade, valorizando a identidade do salão e incentivando o agendamento de serviços.


## ✨ Funcionalidades

- 💇 Banner principal com chamada para ação (CTA);
- 📱 Layout 100% responsivo para desktop, tablet e smartphone;
- 🎨 Design moderno e elegante;
- 🖼️ Galeria de imagens dos serviços;
- 💅 Apresentação dos principais serviços oferecidos;
- ⭐ Destaque para os diferenciais do salão;
- 📞 Seção de contato com fácil acesso às informações;
- ⚡ Navegação simples e intuitiva;
- ✨ Animações para melhorar a experiência do usuário.

---

## 🚀 Tecnologias Utilizadas

- HTML5 🟧
- CSS3 🟦
- JavaScript 🟨


## 📱 Responsividade

A Landing Page foi desenvolvida utilizando técnicas de **Responsive Web Design**, garantindo uma excelente experiência de navegação em diferentes tamanhos de tela, desde smartphones até monitores widescreen.

Este projeto foi desenvolvido com o objetivo de:
